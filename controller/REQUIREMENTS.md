# REQUIREMENTS.md — USB OBS 촬영 컨트롤러

## 1. 개요
책상 위 소형 USB 촬영 컨트롤러. 물리 버튼으로 OBS 녹화 시작/중지 및 장면 전환,
빨간 LED로 OBS 실제 녹화 상태 표시, 소형 OLED에 경과시간+연결상태 표시.

## 2. 기능 요구
| ID | 요구 | 수용 기준 |
|----|------|-----------|
| F1 | REC 버튼: 녹화 토글 요청 | 누르면 host에 `{"cmd":"rec_toggle","seq":n}` 1회 전송 |
| F2 | Scene1/Scene2 버튼: 장면 전환 요청 | 각 장면명으로 `set_scene` 1회 전송 |
| F3 | 빨간 LED = OBS 실제 녹화 상태 | host의 `rec:true/false` 수신시에만 점등/소등 (버튼 직결 점등 금지) |
| F4 | OLED 표시: 경과시간 + 연결상태 | REC 중 MM:SS 카운트, IDLE/NO-LINK/OFFLINE 표시 |
| F5 | USB CDC 시리얼 JSON 라인 프로토콜 | 115200bps, `\n` 종단, `seq` 중복 방지 |
| F6 | 재연결/디바운스/중복명령/상태동기 | 버튼 디바운스 20ms, host 재접속 시 상태 재요청 |

## 3. 비기능/제약
- USB 유선 전용. 무선/배터리 제외.
- USB 5V 500mA 이내 (전원예산 WIRING.md).
- 기성 MCU 개발보드 조립 프로토타입 (납땜 최소화, 브레드보드/점퍼 허용).
- 인증정보 하드코딩 금지 (env/args).
- 실물 제작·꾸미기 금지. 구매/발주/유료생성/배포/커밋 금지.

## 4. 범위 외
- OBS 플러그인 개발, 오디오 믹싱, 스트리밍 제어, 무선 리모컨.
